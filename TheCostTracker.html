Step 1 : Categories Module

Purpose: The Categories module helps you create and manage grouping structures such as Main Category, Raw Material Category, Packing Categories, and more. These categories are used throughout the system for RM Master, PMRM Master, Product Master, BOM, and Reporting.

The Categories Module allows users to define different types of categories required for Raw Materials, Packing Materials, and Size Categories. These master entries are required before creating PMRM Items or Cost Calculations.

1. Main Category

This section is used to define top-level material classifications such as Pesticides, Fertilizers, Packing, Technical, etc.

How to Add a Main Category

  • Go to Categories ➜ Main Category.
  • Enter a category name in the input field.
  • Click the Add button to save.
  • Category will appear in the list below.

📸 Screenshot – Main Categories

Actions Available

  • Edit – Modify an existing category.
  • Delete – Remove the category permanently.
  • Search – Find category items quickly using the search box.

2. RM Category

Used to create categories specifically for Raw Materials (RM). These categories help classify RM materials under relevant groups.

How to Add an RM Category

  • Go to Categories ➜ RM Category.
  • Enter the RM Category name.
  • Click Add to save.

📸 Screenshot – RM Categories

Actions Available

  • Edit – Modify category name.
  • Delete – Remove category.
  • Search – Locate items quickly.

3. PM RM Category

The PM RM Category section defines packaging material categories such as Bottle, Bag, Drum, etc.

How to Add/Update PM RM Category

  • Enter the name (Example: Bottle).
  • Select the type:
    • PM – Packing Material
    • Shipper – Outer packaging
    • Inner – Inner container
  • Click Update to save.

📸 Screenshot – PM RM Categories

Actions Available

  • Edit – Change the name or type.
  • Delete – Remove a PM/RM category.
  • Search – Filter the list easily.

4. Packing Category

The Packing Category section is used to create units like ML, GM, LTR, KG, etc.

How to Add a Packing Category

  • Navigate to Categories ➜ Packing Category.
  • Enter the packing category (Example: ML).
  • Click Add to save.

Available Actions

  • Edit – Update the packing category name.
  • Delete – Remove the packing category.
  • Search – Use search bar to filter list.

📸 Screenshot – Packing Categories

5. Packing Size Category

Packing sizes are linked to a packing category (e.g., GM, ML) with specific size values.

How to Add/Update Packing Size Category

  • Select the Packing Category (Example: GM).
  • Enter the Packing Size (Example: 250.00).
  • Select the Measurement Unit.
  • Click Update to save the changes.

Actions Available

  • Edit – Modify category, size, or measurement.
  • Delete – Remove a packing size entry.
  • Search – Quickly locate entries using search.

📸 Screenshot – Packing Size Categories

Step 2 : PM RM Master

The PMRM Master (Packing Material & Raw Material Master) module is used to store and manage all packing material and raw material items used in production. It acts as the central database for BOM creation, costing, and pricing modules.

1. Purpose of PMRM Master

The PMRM Master helps users:

  • Create and maintain a standardized list of packing and raw materials.
  • Organize materials under correct categories (PM Category / RM Category).
  • Ensure consistent naming across the system.
  • Enable material selection in the BOM (Bill of Material).

How to Add a PMRM Master

  • Navigate to Master ➜ PM RM Master.
  • PMRM Category – Select the category (Bottle, Shipper, Sleeve, etc.)
  • PMRM Name – Enter the actual packing item name (e.g., 500 ML Bottle, Shipper Box)
  • Total Weight of Unit – Enter the total weight of a single unit
  • Per Unit/Kg – Auto-calculated value based on measurement
  • Measurement – Choose ML, GM, KG, or Unit
  • No of Unit – Quantity of packing material
  • Unit/KG – Calculated value that converts the measurement to KG

📸 Screenshot – PM RM Master

Actions Available

  • Edit – Modify an existing PM/RM item.
  • Delete – Remove the PM/RM item permanently.
  • Search – Find PM/RM items quickly using the search box.

Where PMRM Master Is Used

This master is used in:

  • BOM (Bulk Recipe) – Selecting packing/raw material for costing
  • PMRM Price Master – Updating price per unit
  • Finished Goods Pricing – Total product cost calculation
