Step 1 : Categories Module

Purpose: The Categories module helps you create and manage grouping structures such as Main Category, Raw Material Category, Packing Categories, and more. These categories are used throughout the system for RM Master, PMRM Master, Product Master, BOM, and Reporting.

The Categories Module allows users to define different types of categories required for Raw Materials, Packing Materials, and Size Categories. These master entries are required before creating PMRM Items or Cost Calculations.

1. Main Category

This section is used to define top-level material classifications such as Pesticides, Fertilizers, Packing, Technical, etc.

How to Add a Main Category

  • Go to Categories ➜ Main Category.
  • Enter a category name in the input field.
  • Click the Add button to save.
  • Category will appear in the list below.

Actions Available

  • Edit – Modify an existing category.
  • Delete – Remove the category permanently.
  • Search – Find category items quickly using the search box.

How to Add an RM Category

  • Enter the RM Category name.
  • Click Add to save.

Step 2 : PM RM Master

The PMRM Master (Packing Material & Raw Material Master) module is used to store and manage all packing material and raw material items used in production. It acts as the central database for BOM creation, costing, and pricing modules.

1. Purpose of PMRM Master

The PMRM Master helps users:

  • Create and maintain a standardized list of packing and raw materials.
  • Organize materials under correct categories (PM Category / RM Category).
  • Ensure consistent naming across the system.
  • Enable material selection in the BOM (Bill of Material).

How to Add a PMRM Master

  • Navigate to Master ➜ PM RM Master.
  • PMRM Category – Select the category (Bottle, Shipper, Sleeve, etc.)
  • PMRM Name – Enter the actual packing item name (e.g., 500 ML Bottle, Shipper Box)
  • Total Weight of Unit – Enter the total weight of a single unit
  • Per Unit/Kg – Auto-calculated value based on measurement
  • Measurement – Choose ML, GM, KG, or Unit
  • No of Unit – Quantity of packing material
  • Unit/KG – Calculated value that converts the measurement to KG

📸 Screenshot – PM RM Master

Where PMRM Master Is Used

This master is used in:

  • BOM (Bulk Recipe) – Selecting packing/raw material for costing
  • PMRM Price Master – Updating price per unit
  • Finished Goods Pricing – Total product cost calculation

Step 4 : Cost Variable Master

The Cost Variable Master stores all the standard cost inputs used across costing and pricing calculations. Maintain these values centrally so costing reports and BOM calculations stay accurate and consistent.

Purpose

The Cost Variable Master is used to define and manage recurring cost parameters such as:

  • Shift timings, break times and net shift hours
  • Power unit price (per hour)
  • Labour and supervisor charges (per day / per shift)
  • Machine maintenance, loading/unloading, admin, and other overheads
  • Default packing loss or extra expenses used by costing formulas

How to Update Cost Variables

  • From the top menu choose Cost » Cost Variable Master.
  • Change the numeric values in the appropriate fields (for example update Power Unit Price or Labour Charge).
  • Check calculated fields like Net Shift Hours (they update automatically after edits).
  • Click the green Update button to save changes.
  • After update, new values are used in all costing calculations (BulkRecipe, BOM, Formulation, Finish Good Pricing reports).

Step 6 : Formulation Master

The Formulation Master is a crucial module used to define the comprehensive cost structure of a finished product formulation. It integrates various cost components such as labor, power consumption, maintenance, and other overheads to calculate the total production cost and the final cost per unit (Liter/KG).

How to Add/Update a Formulation

To add a new formulation or update an existing one, follow these steps:

  • Formulation Name: Enter the type of formulation (e.g., EC, SC, SG, GR).
  • Measurement: Select the unit of measurement for the batch (e.g., KG or LTR).
  • Batch Size: Enter the total production quantity (in KG or LTR, based on the selected Measurement) for one manufacturing batch.
  • No of Labours: Input the total number of laborers assigned to work on this specific formulation batch.
  • Supervisors: Enter the count of supervisors overseeing this batch.
  • Labour Charge: This field reflects the per-labor cost and is *auto-calculated* based on the number of laborers and the labor rate defined in the Cost Variable Master.
  • Labour Cost: This represents the total calculated labor cost for the batch (e.g., 10-hour or 12-hour shift rate applied per labor).
  • Power (Unit): Enter the total power units (e.g., KWH) estimated to be consumed during the production of this batch.
  • PowerCharge (Unit): This field displays the price per power unit, sourced automatically from the Cost Variable Master.
  • Total Power Cost (Unit): This is an *auto-calculated* field, representing the total power expense for the batch (Power Units × Power Charge).
  • Maintenance: Input any specific machinery maintenance costs associated with this particular batch production.
  • Other Cost: Enter any additional miscellaneous expenses or overheads for the batch.
  • Total Cost: This is an *auto-calculated* field, summing up all ingredient costs (from BOM, if applicable), labor costs, power costs, maintenance, and other expenses for one entire batch.
  • Add Buffer: You can enter an optional additional cost, either as a percentage or a fixed amount, to account for unforeseen expenses or profit margins.
  • CostPerLiter/BatchSize: An *auto-calculated* field that shows the cost per liter or KG before adding any buffer (Total Cost ÷ Batch Size).
  • Final Cost/Ltr BatchSize: This is the *final auto-calculated production cost* per liter or KG, after the 'Add Buffer' amount has been applied.

After entering all the required details, click the Add button to save the new formulation. To discard changes, click Cancel.

Step 9 : Price Master

The Price Master module is used to define and manage the pricing details for Bulk Products and Raw Materials. This pricing is used across cost calculations, NRV calculations, purchase comparisons, and production costing.

1. RM Price Master

The RM Price Master is used to record and manage the purchase prices of raw materials (RM). This information is essential for accurate cost calculations in the BOM and other reports.

How to Add an RM Price Entry

  • Go to Price Master ➜ RM Price Master.
  • RM Category: Select the category of the raw material (e.g., Emulsifier, Solvent).
  • Date of Purchase: Select the date when the material was purchased.
  • RM Name: Choose the specific raw material from the list.
  • Rate/Kg-Ltr(Rs): Enter the base price per unit (Kg or Ltr) of the material.
  • Rate Full Purity: Check this box if the entered rate corresponds to 100% purity of the material. If the material has a lower purity, the system will adjust the price accordingly.
  • Purity(%): Enter the actual purity of the material if it's less than 100%.
  • Actual Price/Kg-Ltr: This field is auto-calculated based on the rate and purity.
  • Quantity: Enter the total quantity purchased.
  • Transport: Add any transportation costs associated with the purchase.
  • Total Rate/Ltr: This is the final calculated cost per unit, including transportation.
  • Click the Add button to save the price entry.

📸 Screenshot – RM Price Master

2. PMRM Price Master

The PMRM Price Master is used to record and manage the purchase prices of packing materials (PM). This is crucial for accurate costing of finished goods.

How to Add a PMRM Price Entry

  • Go to Price Master ➜ PMRM Price Master.
  • PMRM Category: Select the category of the packing material (e.g., Bottle, Shipper).
  • PMRM Name: Choose the specific item from the list (e.g., Bottle 500 ML).
  • Date of Purchase: Select the date when the material was purchased.
  • Price: Enter the base price of the material.
  • Transportation: Add any transportation costs per unit associated with the purchase.
  • No. of Units/KG: Enter the number of units per kilogram, if applicable.
  • Loss (%): Specify any expected loss percentage during handling.
  • Price/Unit: This field displays the final calculated price per unit, considering all inputs.
  • Click the Add button to save the price entry.

📸 Screenshot – PMRM Price Master

3. RM Price Estimate

The RM Price Estimate page is used to record and manage estimated and actual prices for raw materials. This helps in tracking price variations and forecasting before the final prices are available.

How to Add an RM Price Estimate

Step 10 : BOM (Bulk Recipe)

The BOM (Bulk Recipe) Module is where you define the precise formulation for each of your bulk products. This involves selecting ingredients, specifying their quantities and costs, and calculating the final cost of the bulk material before it goes into packaging.

1. How to Create a BOM

First, you need to link a bulk product to a batch size and measurement unit.

  • Navigate to Cost ➜ BulkRecipe (BOM).
  • Select the Main Category (e.g., Pesticides).
  • Choose the Bulk Product you want to create a recipe for (e.g., ABAMECTIN 1.9%).
  • Enter the standard Batch Size (e.g., 1000).
  • Select the Measurement unit (e.g., LTR).
  • Click the Add button to create the BOM entry. It will then appear in the list below.

📸 Screenshot – BOM Creation

2. Input Technical Details (Adding Ingredients)

Once the BOM entry is created, click the Input Technical button for that product to open the recipe definition screen.

Adding Ingredients

  • Use the Search RM dropdown to find and select an ingredient (e.g., ABAMECTIN TECH).
  • If it's an Technical, check the Formulation? box and enter the required purity percentage (e.g., 1.90). The system will calculate the required quantity based on the batch size.
  • For other ingredients like solvents, enter their quantity(ltr/kg) directly.
  • The Rate and Transportation costs are automatically fetched from the price masters.
  • Click Add to include the ingredient in the recipe.
  • Repeat this process for all ingredients in the formula. The system will display the total amount at the bottom.

📸 Screenshot – Recipe Definition

Final Cost Calculation

After adding all ingredients, configure the final costing details at the bottom of the screen:

  • Select the Formulation type (e.g., EC), which add formulation charges.
  • Enter the SPGR (Specific Gravity) and any Form. Lost (%).
  • The system calculates the final Cost/Ltr and Cost Bulk/Ltr based on all inputs.
  • Click the Update button to save the complete recipe and its final cost.

📸 Screenshot – Recipe Definition

Step 11 : Product Packing Material Master

The Product Packing Material Master is used to define the complete packing configuration for a finished product. This includes the primary packing, shipper (outer box), and inner components, along with their respective costs.

1. How to Define a Product's Packing Configuration

This screen allows you to associate a bulk product with its specific packing materials and generate a unique Part Code.

  • Navigate to Master ➜ Product Packing Material Master.
  • Bulk Product: Select the finished bulk product.
  • Packing Name: Choose the primary packing size (e.g., 1 LTR).
  • Shipper Detail: Check the "Shipper" box if an outer box is used. Select the shipper size and the number of units it holds (e.g., 20 units per shipper).
  • Inner Detail: Similarly, configure if there is an inner packing component.
  • Part Code: A unique code is generated based on your selections(If Availables).
  • Click Add to save this packing configuration.

After defining the configuration, you must specify the cost for each packing component.

  • In the product list, find the item you want to price and click the Edit button in the Total Cost/Ltr column.
  • A new window will open. Here, you will add the costs for the Primary Material (PM), Shipper, and any Inner packaging.
  • Type: Select PM, Shipper, or Inner.
  • PM Type / PM Name: Choose the specific packing material (e.g., Pouch).
  • PM Price (Cost/Unit): Enter the cost for a single unit of this material.
  • Click Add. The material and its cost will appear in the table.
  • Add all packing components for the product (e.g., the Pouch itself and the Shipper Box).
  • The Total and Final Pack/Unit costs are calculated automatically.

Step 12 : Packing Style Labour Costing Master

The Packing Style Labour Costing Master is a detailed module for defining the specific labour tasks and power consumption associated with different packing styles. This allows for highly accurate cost calculations for the packing process.

How to Configure Packing Style Labour and Power Costs

In this section, you select all the individual labour activities required for the chosen packing style.

Step 13 : Product wise Labour Cost

The Product wise Labour Cost module is where you calculate the final per-unit cost for a product by combining labor, power, machine output, and other overheads. This screen brings together various master settings to determine the total cost of the packing process for a specific product configuration.

How to Add a Product wise Labour Cost Entry

To calculate the labour and other costs for a product, you need to fill in the details based on its packing style and production line output.

  • Navigate to Cost ➜ Product wise Labour Cost.
  • Bulk Product: Select the bulk product (e.g., ABAMECTIN 1.9%).
  • Packing Size: Choose the packing size for the product (e.g., 1.00-LTR).
  • Packing Style: Select the packing style (e.g., Bottle + Manual Label +Shrink + Shipper). This is pre-configured in the Packing Style Name.

1. Filling Machine Output

  • Storck / Nosel: Enter the number of nozzles on the filling machine.
  • Total Output/Minut/Filling Line: Specify the machine's output per minute.
  • Total Out Put In Liter Or KG/Shift and Total out put Bottels in Net Shift Hours : The system auto-calculates the total production output in Liters or KG per shift based on the machine's output rate.

2. Total Labour Costing

  • Supervisor: Enter the number of supervisors assigned to this packing line.
    The Total Labour & Supervisior Costing is auto-calculated based on rates from the Cost Variable Master.
  • Total Power Cost: The total power consumption cost is automatically calculated based on the power units defined in the Packing Style Labour Costing Master and the power rate from the Cost Variable Master.

3. Other & Final Costing

  • Other Costing: Enter any additional overheads such as Unloading, Loading, Machinary Maintatnce, and Admin Expence.
  • Final Costing: The system calculates the Total Costing by summing up all labor, power, and other expenses. Based on the Total Output in Liter, it provides a Final per liter labour costing.
  • Additional Cost (Buffer): You can add an optional buffer amount per liter to get the final Net Labour Cost/Ltr and Final Per Unit Labour Cost.
  • Click Add to save the entry.

MRP Price Master

The MRP Price Master is a crucial module for setting and adjusting the Maximum Retail Price (MRP) for your finished products. This screen allows you to fetch cost-based suggested prices, apply margins, and set the final MRP along with other company-specific cost components.

How to Set MRP

  • Select Bulk Product: From the "Bulk Product" dropdown menu, choose the product for which you want to set the MRP (e.g., ABAMECTIN 1.9%).
  • Get Data: Click the Get Data button. The system will load a table with all available packing sizes for the selected product, populating it with suggested pricing information.
  • Adjust Margins and Final Prices:

    For each packing size in the table, you can adjust the following editable fields:

    • Percent Of Margin MRP (%): Enter a percentage value here to add a profit margin. This will dynamically adjust the "Suggested MRP."
    • Final MRP: Manually enter the final MRP for the product. This can be the same as the "Suggested MRP" or a different value based on market strategy.
    • PCS Company: Input the value for PCS (Printing, Capping, Sealing) for the company.
    • MHA: Input the value for MHA (Material Handling & Administration).
    • Bulk: Input any additional bulk-related costs or adjustments.
  • Update the Record:

    After entering the desired values, click the blue Update button on the left side of the row to save the changes for that specific product packing.

Price List Terms & Conditions - Other Company Master
